# SEM Bites — Campus Food Ordering

SEM Bites is a campus food ordering website designed to help students explore food items and prepare orders through a simple and user-friendly interface.

## 1. Project Features

- Display food items with prices.
- Browse the campus food menu.
- Add items to a shopping cart.
- View cart items and the total amount.
- Responsive website design.
- Interactive interface using JavaScript.
- Login and payment interface, if implemented in the project.

## 2. Technologies Used

- **Frontend:** HTML5
- **Styling:** CSS3
- **Interactivity:** JavaScript
- **Tools:** Visual Studio Code, Git, and GitHub

## 3. Project Files

- `index.html` — Main website page.
- `style.css` — Website styling and layout.
- `script.js` — Menu, cart, and interactive functionality.
- `logo.png` — Website logo, if included.
- `assets/` — Folder for food images and other resources, if used.

*Update the filenames to match your actual project structure.*

## 4. How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the menu and test the available cart and interface features.

## 5. Project Objective

The objective of SEM Bites is to provide a convenient and easy-to-use campus food ordering interface that allows students to browse food items and manage their selections.

## 6. Future Enhancements

- Backend integration for order processing.
- Database storage for menu items and orders.
- User authentication.
- Online payment integration.
- Order tracking and order history.
